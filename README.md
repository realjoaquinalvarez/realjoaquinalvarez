### Building Talkeo

Open-source, real-time AI for learning languages. A voice tutor you actually talk to, live subtitles, in-place translation, and a native macOS app. I build every layer myself: voice pipeline, backend, infrastructure, web app, and native clients, and I train the voices.

- Real-time voice pipeline at sub-900ms voice-to-voice (WebRTC/LiveKit, STT, multi-provider LLM, TTS), with live language switching.
- Multi-provider routing with automatic fallback and no vendor lock-in, at about 1.5 cents per minute of conversation.
- Python and FastAPI backend deployed to AWS from scratch (ECS Fargate, Terraform, GitHub OIDC).
- Native macOS clients in Swift and SwiftUI: system audio capture, live subtitles, and real-time voice translation.
